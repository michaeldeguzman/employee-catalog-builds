# Employee Catalog (MCP)

This project builds the Employee Catalog app, named EmployeeCatalogMCP on the ODC tenant, with Kiro working through the OutSystems MCP. The folders are `.kiro/steering/` (project rules), `.kiro/specs/` (Kiro specs), `spec-driven-build/` (working files for the outsystems-spec-driven-build skill), `Prompts/` (every prompt sent to Kiro and every Mentor prompt Kiro sends) and `Reports/` (checks of the app against the requirements). SDD Base is the shared, read-only base that holds the generic steering, references and guides.
