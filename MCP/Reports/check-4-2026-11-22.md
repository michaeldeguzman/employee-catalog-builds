### Limit on AC-06

The user did not open a data view in ODC Studio, to avoid an unplanned publish (answer 14). So:

- The total of 20 is inferred: 17 visible active rows plus 3 inactive records found by Id. A record with another Id, for example an extra inactive one, would not have been seen. Two things make an extra record unlikely: the bootstrap action inserts only when the table is empty, and the only call to an Employee create action in the app is the one inside `BootstrapEmployee` (checked on revision 4 in `check-2-2026-11-22.md`). It is not proven.
- For the 3 inactive records, only the name and the Active value were checked, not the job title or the email.

To close the limit, open the Employee data view once (ODC Studio, Data tab, or the ODC Portal) and compare the 20 rows with section 10. This does not need a publish. If the user prefers, a later check can do it.
