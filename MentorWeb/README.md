# MentorWeb

Employee Catalog is an app built with Mentor Web, deployed on the ODC tenant as EmployeeCatalogMW. The folders are `.kiro/` (steering and specs), `BRD/` (generated BRD files for Mentor Web upload), `Prompts/` (every prompt used in Mentor Web or Kiro) and `Reports/` (checks of the app against the requirements). SDD Base is the shared base workspace folder with generic steering and guides, and project files never go there.
